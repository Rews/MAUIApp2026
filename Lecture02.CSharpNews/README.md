# Лекция 2. C# на примере приложения новостей

Готовый проект для демонстрации преподавателем в IDE. Он соответствует второй лекции: **NewsArticle, методы, Action/Func и события, асинхронный источник, коллекции, LINQ и проверка данных**. Домашнего задания к этой лекции пока нет.

Это консольная основа будущего приложения новостей. На следующем занятии начнётся экран MAUI, затем появятся лента, авторизация, избранное и push-уведомления. Здесь нужны только .NET SDK 10 и IDE с поддержкой .NET 10. MAUI, эмулятор, Android SDK, Xcode и внешний сервер для запуска этого примера не требуются.

Все новости вымышлены. `https://example.org/1.jpg` обозначает пример адреса изображения. Сетевых запросов и загрузки картинок в проекте нет.

## Быстрый запуск в Rider

1. Откройте **Lecture02.CSharpNews.sln** из этой папки.
2. Проверьте, что Rider использует .NET SDK 10. `global.json` допускает установленные стабильные feature bands .NET 10; точная версия SDK из первой лекции здесь не требуется.
3. Дождитесь загрузки решения. Выберите **01 News feed** в списке конфигураций и нажмите **Run** или **Debug**.
4. Для других частей рассказа выбирайте конфигурации ниже. Для ввода в режиме **04 Preview input** щёлкните консоль запуска, введите значение и нажмите Enter.

Конфигурации Rider сохранены в `.run`. В `NewsAppDemo/Properties/launchSettings.json` есть те же семь профилей для IDE, поддерживающих профили запуска .NET. Без параметров программа выполняет обычный сценарий ленты.

| Конфигурация | Аргумент | Что показывает |
|---|---|---|
| **01 News feed** | `--demo` | `await`, три новости, `foreach`, LINQ и короткий анонс |
| **02 References and null** | `--references` | Две ссылки на один объект, изменение заголовка, `?.` и `??` |
| **03 Task and await** | `--async` | Короткий `LoadTitleAsync` со слайда 14 |
| **04 Preview input** | `--interactive` | `TryParse`, положительная длина анонса и повтор ввода |
| **05 Model errors** | `--errors` | `throw`, `try/catch` и сохранение корректного состояния |
| **06 Delegates Action Func** | `--delegates` | Вызовы `Action` и `Func`, передача действия в метод, слайд 10 |
| **07 Events subscribe unsubscribe** | `--events` | `TitleChanged`, подписка, уведомление и отписка, слайд 11 |

В другом редакторе можно открыть проект `NewsAppDemo/NewsAppDemo.csproj` и передать соответствующий аргумент запуска.

## Запуск из терминала

Команды выполняются **из папки Lecture02.CSharpNews**:

```bash
dotnet build Lecture02.CSharpNews.sln
dotnet run --project NewsAppDemo -- --demo
dotnet run --project NewsAppDemo -- --references
dotnet run --project NewsAppDemo -- --async
dotnet run --project NewsAppDemo -- --interactive
dotnet run --project NewsAppDemo -- --errors
dotnet run --project NewsAppDemo -- --delegates
dotnet run --project NewsAppDemo -- --events
```

Например, тот же запуск через профиль:

```bash
dotnet run --project NewsAppDemo --launch-profile "03 Task and await"
```

Проект не использует сторонних NuGet-пакетов. `NuGet.Config` ограничивает источники общедоступным nuget.org, чтобы локальные закрытые feeds не мешали восстановлению.

## Ожидаемые результаты

В **01 News feed** после имитации загрузки выводятся три новости. Затем:

```text
УрФУ: библиотека, УрФУ: лаборатория
Анонс: Открыт новый
```

В **02 References and null** сначала обе ссылки дают заголовок «Новый зал», затем появляется «Не выбрана». Исходный объект продолжает существовать через `article`.

В **03 Task and await** после сообщения о загрузке появляется «УрФУ: библиотека».

В **04 Preview input** последовательно введите:

| Ввод | Результат |
|---|---|
| `двенадцать` | Сообщение о неверном числе, новая попытка |
| `0` | Сообщение о неверном числе, новая попытка |
| `12` | `Открыт новый` |
| `100` | `Открыт новый зал.` |
| пустая строка | Сообщение о неверном числе, новая попытка |
| `выход` | Завершение программы |

Конец входного потока тоже завершает диалог. Число вне диапазона `int` отклоняется без аварийного завершения.

В **05 Model errors** нулевая длина вызывает понятное сообщение, после чего программа получает корректный анонс. Попытка записать пустой заголовок отклоняется, исходный заголовок сохраняется.

В **06 Delegates Action Func** заголовок «УрФУ: библиотека» выводится трижды: через Action, после получения строки из Func и при передаче Action в ShowArticle. Сам вызов Func возвращает значение; вывод выполняет Console.WriteLine.

В **07 Events subscribe unsubscribe** после подписки обработчик выводит «Новый зал» один раз. Присваивание того же заголовка с пробелами по краям не вызывает нового уведомления. После отписки объект получает заголовок «Другой зал», но обработчик больше не вызывается. Последняя строка отдельно показывает текущее состояние объекта.

## Правила примера

- Заголовок и текст обязательны. Заголовок очищается от пробелов по краям.
- `ImageUrl` может быть пустой строкой, если картинки нет. Доступность адреса здесь не проверяется.
- `RenameTitle` после проверки и Trim меняет заголовок и вызывает `TitleChanged`. Если заголовок не изменился, уведомления нет. При неверном вводе нет ни изменения, ни уведомления. Это изменение объекта в памяти.
- `TitleChanged` имеет тип `Action<NewsArticle>` и передаёт подписчикам текущую новость с новым заголовком. Внешний код использует `+=` и `-=`. Вызвать событие можно внутри NewsArticle. `?.Invoke` допускает отсутствие подписчиков.
- Обработчики в примере выполняются синхронно внутри `RenameTitle`. `event` сам по себе не запускает Task или отдельный поток.
- `Action<NewsArticle>` не возвращает значение, а `Func<NewsArticle, string>` возвращает заголовок. Для отписки используется та же переменная handler, что и для подписки.
- `GetPreview` принимает положительную длину. Если предел больше текста, возвращается весь текст. Ноль и отрицательная длина вызывают `ArgumentOutOfRangeException`.
- Анонс не меняет полный текст и не добавляет многоточие. `Substring` работает с единицами UTF-16; для полноценного анонса со сложными символами нужно учитывать границы текстовых элементов. Здесь используем простой учебный текст.
- Поиск `Contains("УрФУ")` учитывает регистр. LINQ создаёт список заголовков и не изменяет исходную ленту.
- Каждый вызов `DemoNewsSource` создаёт новый список и новые объекты.
- `Task.Delay` имитирует задержку. `Task` сам по себе не означает отдельный поток. Консольный пример показывает порядок выполнения, но не работу UI-потока.

Сокращённые фрагменты на слайдах раскрывают отдельные конструкции. Полный проект добавляет проверки конструктора, точку входа и цикл повторного ввода.
