## Проверка поведения

- Ссылки: обе переменные видят новый заголовок; присваивание null одной ссылке не мешает другой.
- Наследование: вызов GetContentKind через NewsArticle возвращает «Видео» для VideoNewsArticle. Несовместимое приведение обрабатывается.
- Делегаты: Action, вывод результата Func и переданное в метод действие дают три вывода заголовка.
- События: экран вызывается один раз, журнал — два; повторный заголовок не уведомляет. После отписки экрана журнал получает «Другой зал»; после обеих отписок состояние меняется без уведомлений.
- Task с результатом: порядок сообщений 1, 2, 3, 4; после await — строка и IsCompletedSuccessfully=True.
- Task без результата: успешная операция выводит сообщение о завершении; ошибочная — catch и IsFaulted=True. Программа продолжает работу.
- LINQ: два результата после Where, библиотека первая после OrderBy, строки после Select; в исходном списке остаются три элемента и лаборатория первой.
- Интерактивный ввод непосредственно в Rider: «двенадцать» и 0 отклонены с повторным приглашением, 12 возвращает «Открыт новый», 100 — «Открыт новый зал.», « ВЫХОД » завершает программу.
- Дополнительная проверка ввода через .NET: -1, 2147483648 и пустая строка отклонены; int.MaxValue возвращает полный текст; конец входного потока штатно завершает цикл.
- Защита модели: после ошибочной длины корректный вызов работает; пустой заголовок не меняет прежнее состояние.
- Без аргументов вывод совпадает с --demo. Неизвестный режим и два аргумента дают код 1.
