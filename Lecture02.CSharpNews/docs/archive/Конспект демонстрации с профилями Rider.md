# Лекция 2. Демонстрация C# в Rider

Готовое консольное демо на примере новостей. Все темы запускаются в одном решении; заменять содержимое `Program.cs` между показами не нужно. Номера разделов ниже совпадают с конфигурациями Rider и профилями .NET. В Rider перед именем профиля отображается префикс `NewsAppDemo:`.

[[УРФУ/Курс мобильной разработки 2026/02. Основы CSharp/Конспект лекции.md|Конспект лекции]]

## Цель и необходимые знания

Показать, как из базовых конструкций C# складываются модель новости, подписка на изменения, асинхронное получение списка и проверка ввода. Результат: студент может проследить изменение объекта, объяснить различия Action/Func/event и Task/`Task<T>`, прочитать LINQ и найти обработку некорректных данных.

Базовые переменные, условия и циклы сначала повторяем. Продолжительность выбирает преподаватель: фиксированный хронометраж не является условием работы демо. Для короткого показа можно пройти 04 → 05 → 08 → 09 → 10 → 11 → 12 → 13, остальные примеры использовать для повторения.

Все новости вымышлены. Адреса `example.org` — строки, сетевых запросов и загрузки изображений/видео нет. `Task.Delay` имитирует ожидание. MAUI, MVVM, сервисы и эмуляторы для этого консольного проекта не нужны.

## Точность объяснений

- `var` выводит статический тип; это не динамическая переменная и не запрет переприсваивания.
- Nullable-аннотации ссылок помогают анализу компилятора. Постфиксный `!` подавляет предупреждение, но не предотвращает NullReferenceException. В этом проекте nullable-анализ включён в csproj, предупреждения считаются ошибками сборки.
- Числовое преобразование, разбор строки и приведение ссылки — разные операции. Приведение ссылки не создаёт копию и не превращает обычную новость в видеоновость.
- `TitleChanged` уведомляет только после изменения заголовка. Повтор после Trim и неверное значение не вызывают уведомления. Подписка сама по себе не вызывает обработчик; для отписки используются те же переменные делегатов.
- В примере обработчики события синхронно выполняются внутри RenameTitle. `event` не создаёт поток или Task. Action выбран для первого знакомства; EventHandler и уведомления свойств можно разобрать позже.
- Вызов async-метода начинает выполнение; await получает результат либо ожидает завершения незавершённой операции без блокирующего ожидания потока. Task не является потоком. Консольный пример не проверяет отзывчивость UI. Не заменять await на Result/Wait и не вводить async void для этих операций.
- `Task` без параметра типа позволяет дождаться завершения, но не даёт строкового результата. Ошибка из показанной async-операции наблюдается через await и обрабатывается catch. Отмена и параллельные загрузки остаются за пределами демо.
- В CollectionsDemo каждый шаг материализован через ToList ради просмотра промежуточного результата. В NewsFeedDemo та же идея записана одной цепочкой. Новые списки NewsArticle содержат ссылки на прежние объекты; глубокого копирования нет.
- Ordinal и StringComparer.Ordinal задают воспроизводимое сравнение с учётом регистра; это технический порядок, а не локализованная сортировка интерфейса.
- GetPreview не добавляет многоточие и работает с единицами UTF-16. Для произвольных сложных символов понадобятся границы текстовых элементов; здесь используется простой учебный текст.
