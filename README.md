# MAUIApp2026

Демонстрационные проекты курса мобильной разработки на .NET MAUI, 2026 год.

| Занятие | Проект | Содержание |
|---|---|---|
| 1. Мобильная разработка и экосистема .NET | [Lecture01.MauiDemo](Lecture01.MauiDemo/) | Стандартное приложение, структура проекта, XAML и C#, запуск и отладка |
| 2. C# для разработки приложений | [Lecture02.CSharpNews](Lecture02.CSharpNews/) | Модель новости, методы, коллекции, LINQ, интерфейс источника, Task/await и обработка ошибок |

Каждое демо находится в отдельной папке со своим решением и инструкцией запуска.

Начиная со второй лекции сквозной пример — **приложение новостей**. Сначала описываем заголовок, текст и ссылку на изображение. Затем добавляем мобильные экраны, сеть, авторизацию, избранное и push-уведомления.
