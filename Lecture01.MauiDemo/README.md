# Лекция 1. Мобильная разработка и экосистема .NET

Стандартное приложение .NET MAUI: экран Hello, World! и кнопка-счётчик. Разметка и обработчик из демонстрационного проекта сохранены.

## Запуск в Rider

1. Установите .NET SDK **10.0.300** и компоненты MAUI для своей платформы. Версии SDK и workload set закреплены в `global.json`.
2. Установите инструменты целевой платформы: Android SDK и JDK для Android; совместимый Xcode и iOS Simulator для iOS на Mac.
3. Откройте `Lecture01.MauiDemo.sln` и восстановите NuGet-пакеты.
4. В **Settings → Build, Execution, Deployment → Toolset and Build** проверьте путь к .NET CLI и MSBuild из SDK 10.0.300. Старый Mono MSBuild для этого проекта не подходит.
5. Выберите конфигурацию `Debug Android`, `Debug iOS` или `Debug macOS`, затем доступное устройство или симулятор. Для Android в Rider нужен совместимый плагин Android Support.
6. Нажмите **Debug**. Для проверки остановки поставьте точку на `count++` в `MainPage.xaml.cs` и нажмите кнопку в приложении. **Resume** продолжает выполнение.

Пути к SDK, JDK и Xcode настраиваются локально в IDE: персональных путей и идентификаторов эмуляторов в репозитории нет.

## Маршрут демонстрации

1. Работающее приложение и кнопка-счётчик.
2. `Lecture01.MauiDemo.csproj`: один проект, несколько целевых платформ.
3. `MainPage.xaml`: интерфейс, `Text`, `x:Name`, `Clicked`.
4. `MainPage.xaml.cs`: обработчик, счётчик, точка останова и переменные.
5. `MauiProgram.cs`: настройка приложения.
6. `App.xaml` и `App.xaml.cs`: ресурсы и создание окна.
7. `AppShell.xaml`: корневая страница и навигация.
8. `Resources`: изображения, шрифты, стили и иконка.
9. `Platforms`: платформенные точки входа и настройки.
10. Запуск одного проекта на Android, iOS и macOS через Mac Catalyst.
